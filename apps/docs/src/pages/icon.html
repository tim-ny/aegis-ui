Icon

<x-icon />

Render any Tabler icon with size, color and accessibility handled.

Usage

Props

Prop Type / Options Default Description
name string — Tabler icon name (with or without tabler- prefix).
size xs, sm, md, lg, xl md Scale.
color string inherit Applies currentColor by default.
label string null Sets aria-label; null renders decorative.
